# PantryPilot final release checklist

## Product and safety

- [ ] Golden Journey passes from a fresh Prepare demo reset.
- [ ] Agent Trace shows running, success, needs-user and error correctly.
- [ ] Shopping list changes only after a human click.
- [ ] No tool can purchase, pay or place an order.
- [ ] Plan, cooking progress, timers and trace survive reload.
- [ ] Desktop and mobile layouts have no clipping or overlap.

## Engineering

- [ ] `npm test` passes.
- [ ] `npm run build` passes.
- [ ] All ten WebMCP tools appear in a compatible browser.
- [ ] Tool descriptions and outputs remain inside documented budgets.
- [ ] GitHub Actions CI and Pages deployment are green.
- [ ] Public Live URL opens without authentication.

## Submission

- [ ] Devpost text proofread and pasted.
- [ ] Public GitHub repository linked; MIT license visible.
- [ ] English demo video is below three minutes and has audible narration.
- [ ] Public YouTube URL added to Devpost and `submission/DEVPOST.md`.
- [ ] Full submission rehearsed once from a private browser window.
- [ ] Submit by 3 September 2026, 18:00 CEST target buffer.
